# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment, personal attacks, discriminatory language and publishing anyone's private information (including financial data) are not acceptable in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour to **rkushwaha8610@gmail.com**. Reports are handled confidentially. The maintainer may remove comments, lock threads or block participants who break this code, as described in the Covenant's enforcement guidelines.
